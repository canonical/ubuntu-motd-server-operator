# ubuntu-motd-server Terraform product module

This folder contains a [Terraform][Terraform] product module, as defined by CC008
(Terraform module standards), that deploys the complete `ubuntu-motd-server` solution:
the `ubuntu-motd-server` charm plus the `gateway-api-integrator` and
`gateway-route-configurator` charms (consumed via the
[gateway-api-integrator-operator][gateway-api-integrator-operator] product module) and
the integration tying them together.

The module uses the [Terraform Juju provider][Terraform Juju provider] to model the
deployment onto any Kubernetes environment managed by [Juju][Juju].

## Module structure

- **main.tf** - Defines the Juju applications and integrations to be deployed.
- **locals.tf** - Resolves the effective channel of each bundled charm from `risk` when a
  per-charm `channel` is not explicitly set.
- **variables.tf** - Allows customization of the deployment, including the Juju model
  UUID, the `risk` level, per-charm configuration, and external integrations
  (`certificates`, `logging`) that this solution requires but does not bundle.
- **outputs.tf** - Exposes the deployed applications, the provided integration
  endpoints, and the `models`/`metadata` describing this deployment.
- **terraform.tf** - Defines the Terraform and Juju provider versions.

## Using this product module

Always pin the `?ref=` to a released tag or a commit hash: CC008 does not allow floating
references such as branches.

```text
module "ubuntu_motd_server_product" {
  source = "git::https://github.com/canonical/ubuntu-motd-server-operator//terraform-product?ref=tf-1.0.0"

  model_uuid = data.juju_model.my_model.uuid
  # (Customize configuration variables here if needed)
}
```

To integrate the solution's external requirements, supply the `certificates` and/or
`logging` input variables with the endpoint or offer to integrate with, for instance:

```text
module "ubuntu_motd_server_product" {
  source = "git::https://github.com/canonical/ubuntu-motd-server-operator//terraform-product?ref=tf-1.0.0"

  model_uuid = data.juju_model.my_model.uuid

  certificates = {
    kind     = "endpoint"
    name     = "self-signed-certificates"
    endpoint = "certificates"
  }
}
```
